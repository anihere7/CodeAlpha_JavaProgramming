# Student Grade Tracker

A simple console-based Java application for managing student grades and generating a summary report.

## 📌 Task 1 – CodeAlpha Java Programming Internship

This project was developed as part of the **CodeAlpha Java Programming Internship**.

The application allows users to enter student information and their grades, then calculates and displays:

- Average score
- Highest score
- Lowest score
- Complete student summary report

## 🚀 Features

- Add multiple students
- Enter multiple subject grades for each student
- Calculate average grade
- Find highest grade
- Find lowest grade
- Display a complete summary report
- Console-based user interface
- Uses Java `ArrayList` for dynamic data storage

## 🛠️ Technologies Used

- **Java**
- **ArrayList**
- **Scanner**
- Object-Oriented Programming (OOP)
